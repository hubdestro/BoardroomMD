# BoardroomMD

BoardroomMD is a purely client-side, zero-infrastructure SaaS web application designed to convert raw Markdown (typically generated by AI tools) into highly styled, professional Word documents (`.docx`).

## Features
- **Zero Infrastructure:** Operates 100% in the browser. No backend, no server-side rendering, ensuring privacy and immediate document generation.
- **AST Mapping:** Maps Markdown tokens directly to native `docx` components for precise, structured Office Open XML generation, avoiding the pitfalls of HTML-to-print conversion.
- **Template Engine:** Separates presentation from content. Provides configurable templates with a global style dictionary (fonts, colors, spacing) and document chrome (cover pages, headers, footers).
- **Graceful Fallbacks:** Built to handle malformed or unsupported Markdown gracefully.

## Tech Stack
- **UI:** Plain HTML5, Tailwind CSS (via CDN), Vanilla JavaScript (ES6+).
- **Markdown Parsing:** [marked.js](https://marked.js.org/) (for AST generation).
- **Document Generation:** [docx](https://docx.js.org/) by Dolan Miu.
- **File Export:** [FileSaver.js](https://github.com/eligrey/FileSaver.js/).

## Usage
Simply clone this repository and open `index.html` in your browser. No build steps or node packages are required to run the core application.

```bash
git clone https://github.com/yourusername/BoardroomMD.git
cd BoardroomMD
# Open index.html in your preferred browser
open index.html # On macOS
```
